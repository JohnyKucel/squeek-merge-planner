# Squeek Merge Planner

A utility for Squeek NFT holders on Squeekchain. Enter how many Squeeks you hold per level and it computes the optimal merge ladder: which pairs are ready to merge, total merges to max out, the highest level reachable, and a step-by-step merge plan.

Built on Squeekchain's merge mechanics (two same-level Squeeks merge into a higher level, up to level 10) and the public Squeekchain API as reference for levels and merge state.

## Live site

https://johnykucel.github.io/squeek-merge-planner/

## How to use

1. Enter how many Squeeks you hold at each level (L1–L8).
2. The planner shows ready merge pairs, total merges to max, the highest reachable level, and a copyable step-by-step merge sequence.
3. Use the Example button to load a sample, or Reset to clear.

## Built for

Squeekchain Genesis Code program — a utility for holders.
