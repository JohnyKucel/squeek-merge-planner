Masukin jumlah Squeek yang kamu punya per level. Planner ini langsung ngitung: mana yang bisa di-merge sekarang, hasilnya naik ke level berapa, dan kurang berapa lagi buat target kamu.

Aturannya cuma 1: 2 Squeek level sama = 1 Squeek level di atasnya

Ini buat apa di Genesis Code?

Squeekchain lagi buka program Genesis — Code: bikin tool / game / aplikasi buat Squeekchain, terus project-nya direview. Planner ini contoh paling sederhananya — tool beneran yang dipakai holder buat ngatur merge, bukan sekadar halaman pajangan.

  1. Build — bikin tool-nya
  2. Prove it's yours — buktiin ini punya kamu
  3. Swarm Review — dinilai, lolos = dapat badge

1 · Squeek kamu sekarang

Isi jumlah per level. Pakai tombol + / − atau ketik langsung. Belum punya di level itu? Biarin 0.

Piramida merge

Tiap naik 1 level, jumlah yang dibutuhkan dobel. Bar oranye = level yang kamu punya isinya. Garis hijau = target kamu.

    Kalau mau submit project ini ke Genesis Code

    Submit & verifikasi itu gratis. Urutannya gini, pelan-pelan aja:

    • 1
      Selesaiin tool-nya duluProject harus beneran jadi dan bisa dipakai orang — bukan halaman kosong atau janji doang.
    • 2
      Pasang live di domain kamu sendiriBuat jalur submit langsung (tanpa IMD): tim Squeekchain kasih 1 DNS record buat dipasang di domain kamu.
    • 3
      Pasang page tag di situsnyaTag kecil yang mereka kasih, dipasang di halaman yang live itu.
    • 4
      Bikin repo GitHub publik + tulis 1 baris di READMEBaris repository yang mereka kasih ditempel di README repo project kamu.
    • 5
      Tekan Verify, tunggu review timAda cek otomatis dulu, lalu tim Squeekchain review. Lolos = project muncul di board.
    • 6
      Jangan dihapus-hapusRekor verifikasi dicek ulang tiap hari. Kalau DNS / tag / baris README hilang, project gagal — dan badge-nya bisa ikut hilang.

    Jalur satunya: bangun pakai IMD swarm. Kalau pakai IMD, project dianggap punya wallet yang bayar job pertamanya — jadi bayar dari wallet yang sudah terverifikasi di profil Genesis kamu (wallet biasa, bukan smart-contract wallet). Biaya IMD-nya yang bayar, submit-nya tetap gratis.
